## Ordena

Siga os passos abaixo para rodar a aplicação em seu ambiente local:

### 1. Clonar o Repositório

```bash
git clone [https://github.com/seu-usuario/ordena.git](https://github.com/seu-usuario/ordena.git)
```


### 2. Instalar as Dependências

```bash
npm install
```

### 3. Executar o Servidor de Desenvolvimento

```bash
npm run dev
```

Após executar o comando, acesse **http://localhost:5173** no seu navegador para ver a aplicação rodando.
